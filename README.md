# prboard → PR Marmot

**This project has been renamed.** prboard is now **PR Marmot** (`prmarmot`) and lives at:

## https://github.com/oliver-kriska/prmarmot

Everything moved there: source, releases (v0.1.0 – v0.5.3 were published under the old name), issues, and the installer.

- Install: see the README at https://github.com/oliver-kriska/prmarmot#install
- Releases: https://github.com/oliver-kriska/prmarmot/releases
- Issues and discussions: https://github.com/oliver-kriska/prmarmot/issues

If you have an existing clone, point it at the new remote:

    git remote set-url origin https://github.com/oliver-kriska/prmarmot.git

If you installed the app under the old name (`~/Applications/prboard.app`, config in `~/.config/prboard/`), the new version migrates your config automatically on first launch; the old app bundle can be deleted.

Why the rename: another product already used the name prboard, and the marmot — the alpine sentinel that whistles when something needs attention — is what the app does for your pull requests.

This repository exists only as a pointer and will not receive updates.
